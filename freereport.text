─────────────────────────────────────────────
PATHWAY ENGINE
─────────────────────────────────────────────

DATA SOURCE:
Use Energy-Performance-Rating from each 
improvement in API recommendations.
Sequential SAP subtraction:
Measure 1 uplift = Measure1.EPR - currentSAP
Measure 2 uplift = Measure2.EPR - Measure1.EPR
Measure 3 uplift = Measure3.EPR - Measure2.EPR

Current SAP from API.
Target SAP: 69 (band C threshold).
Gap = 69 - currentSAP

SUPPLEMENTARY MEASURES (fallback only):
If API returns fewer than 3 measures add:
- Draught proofing (uplift: +1, cost: £200-£300, 
  difficulty: low)
- Heating controls (uplift: +2, cost: £300-£500,
  difficulty: low)
- Cylinder insulation (uplift: +1, cost: £50-£150,
  difficulty: low)

SOLAR PV SPECIAL RULE:
If not in API recommendations but adding it
would achieve C → include in pathway boxes
with caveat:
"Solar PV not on your EPC recommendations
but could contribute toward EPC C —
subject to planning permission and roof survey"

ASHP SPECIAL RULE:
Only show for off-gas properties
Flag: "ASHP suitability requires survey —
contact GoGreen Alliance for free assessment"

LISTED/CONSERVATION OVERRIDE:
If listed = Yes OR conservation = Yes:
Filter measures to low difficulty only:
heating controls, draught proofing,
cylinder insulation, low energy lighting

If filtered measures reach C → show normal boxes
If filtered measures don't reach C:
→ Skip boxes 1/2/3
→ Show message:
"This property's listed/conservation status 
limits standard improvement options. 
Only low-disruption internal measures 
are likely to be permitted."
→ Go straight to Outcome 4

SCORING SYSTEM:
Factor 1 — Measures:
Single = 1, Dual = 2, Three+ = 3

Factor 2 — Cost band:
Under £2,000 = 1 (Low)
£2,000-£7,000 = 2 (Medium)
Over £7,000 = 3 (High)

Factor 3 — Difficulty:
Low (1): heating controls, draught proofing,
         cylinder insulation, low energy lighting
Medium (2): loft insulation, cavity wall,
            secondary glazing, solar PV
High (3): internal wall insulation, 
          external wall insulation,
          ASHP, floor insulation,
          first time central heating

Combined score = Factor1 + Factor2 + Factor3

ACHIEVABILITY LABELS:
Score 3-4: Straightforward
           "Low cost / Low disruption"
Score 5-6: Achievable  
           "Low cost / Some disruption"
Score 7-8: Challenging
           "Mid cost / Disruption involved"
Score 9:   Difficult
           "High cost / Significant complexities"
